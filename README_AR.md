# Amazon.eg Used Tracker — النسخة الأولى

## ما الذي يعمل الآن؟
- واجهة عربية متجاوبة للموبايل والكمبيوتر.
- قاعدة SQLite لحفظ عروض المستعمل.
- ترتيب حسب أول وقت اكتشاف العرض.
- منع التكرار باستخدام `offer_id` ثابت.
- تحديث الواجهة كل 5 ثوانٍ.
- فحص مصدر البيانات من الخادم كل 60 ثانية (أو أكثر؛ الحد الأدنى في هذا الإصدار دقيقة).
- بيانات تجريبية اختيارية ومعلّمة بوضوح.

## المتطلبات
Python 3.10+

## التشغيل على الكمبيوتر
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```
ثم افتحي: http://127.0.0.1:8000

## ربط مصدر البيانات
أنشئي ملف `.env` أو عيّني متغيرات البيئة:
- `PROVIDER_URL`: رابط API لمزوّد بيانات مصرح به يعيد JSON.
- `PROVIDER_TOKEN`: اختياري، إذا كان المزوّد يستخدم Bearer token.
- `POLL_SECONDS=60`

شكل الاستجابة المتوقع:
```json
{
  "offers": [
    {
      "offer_id": "unique-offer-id",
      "asin": "B0XXXXXXXX",
      "title": "Product title",
      "price": 1200,
      "currency": "EGP",
      "condition": "Used - Very Good",
      "seller": "Seller name",
      "product_url": "https://www.amazon.eg/dp/...",
      "image_url": "https://..."
    }
  ]
}
```
يجب أن يعيد المزوّد `offer_id` مختلفًا لكل عرض/بائع/حالة، وليس ASIN فقط؛ لأن المنتج الواحد قد يكون له أكثر من عرض مستعمل.

## تنبيه مهم بخصوص التغطية
هذا المشروع لا يجمع كل عروض أمازون تلقائيًا من تلقاء نفسه. يحتاج إلى مصدر بيانات يدعم Amazon.eg وعروض Used. واجهات Amazon الرسمية التي تتيح البحث عن منتجات لا توفر بالضرورة بثًا شاملًا بكل العروض الجديدة في السوق. لا تستخدم كشطًا يتجاوز شروط أمازون أو يتخطى وسائل الحماية.

## النشر على الإنترنت
هذه النسخة تعمل محليًا. لجعلها موقعًا متاحًا من الموبايل والكمبيوتر في أي مكان، يلزم نشرها على استضافة تدعم Python/ASGI مع تخزين دائم لقاعدة البيانات، ثم ربط اسم نطاق اختياريًا.
